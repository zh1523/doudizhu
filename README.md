# 斗地主 - 在线对战平台

Web 端斗地主游戏，支持 AI 单机对战和多人联机对战。

## 快速开始

```bash
# 1. 安装依赖
cd client && npm install
cd ../server && npm install

# 2. 构建前端
cd client && npm run build

# 3. 启动服务端
cd ../server && npm run dev
```

浏览器打开 `http://localhost:3000`

## 游戏功能

- **AI 对局**：与电脑对战，点击准备即开始
- **玩家对局**：3 人联机，全部准备后开局
- **发牌动画**：渐进式发牌，84 毫秒完成
- **叫地主**：1/2/3 分叫地主，无人叫则重新发牌
- **手牌提示**：智能提示当前最优出牌
- **10 种牌型**：单/对/三带/顺子/连对/飞机/炸弹/火箭
- **视角旋转**：每个玩家始终看到自己在下方
- **断线检测**：10 秒超时，关页面前主动通知
- **历史对局**：SQLite 记录每局结果和玩家统计

## 牌型体系

| 牌型 | 说明 | 例 |
|------|------|-----|
| 单牌 | 1 张 | ♠3 |
| 对子 | 2 张同值 | ♠3 ♥3 |
| 三条 | 3 张同值 | ♠3 ♥3 ♦3 |
| 三带一 | 3 + 1 | ♠3 ♥3 ♦3 + ♠5 |
| 三带二 | 3 + 对 | ♠3 ♥3 ♦3 + ♠5 ♥5 |
| 顺子 | ≥5 张连续 | 34567 |
| 连对 | ≥3 对连续 | 334455 |
| 飞机 | ≥2 组连续三条 | 333444 + 带牌 |
| 炸弹 | 4 张同值 | ♠3 ♥3 ♦3 ♣3 |
| 火箭 | 大小王 | 🃏🃏 |

牌力：3 < 4 < ... < 10 < J < Q < K < A < 2 < 小王 < 大王
